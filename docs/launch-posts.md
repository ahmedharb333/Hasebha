## Show HN

**Title:** Show HN: Klar – an MCP server for Jordan/GCC labour-law, tax and finance math

**Body:**

LLMs are confidently wrong at the calculations people most need to trust — end-of-service gratuity, income tax, social insurance, notice periods. These are set by statute and differ by country, so a model that "reasons" its way to a number is a liability.

Klar is a remote MCP server that answers them from rules instead of guesses, for Jordan, Saudi Arabia, UAE, Kuwait, Qatar, Bahrain and Oman. It returns the figure together with the assumptions and the legal basis, so an agent can quote it and explain it. It also covers the everyday finance, business, health, education, date and unit calculators an assistant reaches for constantly — 36 tools total.

It's deterministic (no model in the loop), stateless (no inputs stored or logged), and every result carries its own assumptions and limitations. Statutory tools note that contracts may exceed the statutory minimum; health tools flag that they're estimates, not medical advice.

Endpoint and tool list: https://worldly.pro/agents/

Happy to answer questions about the design — especially the choice to make every calculator return its assumptions as first-class data.
